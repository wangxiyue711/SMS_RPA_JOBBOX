## 🚀 初回セットアップ

### ステップ1: 依存関係のインストール

`install_indeed_uploader.cmd` をダブルクリックして実行します。

これにより以下のパッケージがインストールされます：
- `gspread` (Google Sheets API クライアント)
- `google-auth` (Google認証ライブラリ)

### ステップ2: Google Spreadsheet ID の取得

1. アップロード先の Google Spreadsheet を開きます
2. URLから Spreadsheet ID をコピーします：

   ```
   https://docs.google.com/spreadsheets/d/1T9_xa3Ej-heRZcQrTcTe2x6PINKP_zEz0mT_Rwf4VTI/edit
                                          ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑
                                          この部分が Spreadsheet ID です
   ```

### ステップ3: 設定ファイルの編集

`config/indeed_config.json` を開いて、以下の項目を編集します：

```json
{
  "enabled": true,  // ← false から true に変更
  "spreadsheet_id": "YOUR_SHEET_ID_HERE",  // ← コピーした ID に置き換え
  "sheet_name": "管理表",  // ← シート名を確認
  ...
}
```

**重要**: `enabled` を `true` にしないとアップロードできません！

## 📝 基本的な使い方

### ステップ1: ツールを起動

`run_indeed_upload.cmd` をダブルクリックして起動します。

### ステップ2: CSV ファイルを選択

1. 「📂 CSV ファイルを選択」ボタンをクリック
2. Indeed からダウンロードした CSV ファイルを選択
3. データプレビューが自動的に表示されます（最大10件）

### ステップ3: アップロード実行

1. プレビューでデータを確認
2. 「🚀 アップロード実行」ボタンをクリック
3. 確認ダイアログで「はい」を選択
4. アップロード進捗がログに表示されます

### ステップ4: 完了

- 成功件数、スキップ件数、エラー件数が表示されます
- Google Spreadsheet を開いて結果を確認してください

## ⚙️ 設定のカスタマイズ

### GUI から設定を変更

ツール内の「⚙️ 設定」ボタンから以下を変更できます：

- ✅ アップロード機能の有効/無効
- ✅ Spreadsheet ID
- ✅ シート名
- ✅ 重複チェックの有効/無効
- ✅ 重複チェックに使用する列

### 設定ファイルで詳細設定

`config/indeed_config.json` を直接編集して、より詳細な設定が可能です：

#### デフォルト値の設定

```json
"default_values": {
  "進捗": "新規",        // 空欄の「進捗」列に自動で「新規」を設定
  "流入": "Indeed",      // 空欄の「流入」列に自動で「Indeed」を設定
  "担当CA": "山田太郎"   // 空欄の「担当CA」列に自動で「山田太郎」を設定
}
```

#### 公式の設定

特定の列に自動的に公式を挿入できます：

```json
"formulas": {
  "C列(memo3)": "=COUNTIFS($K$3:$K{row},K{row},$L$3:$L{row},L{row})",
  "B列(memo2)": "=$K{row}&$L{row}&$C{row}",
  "重複": "=COUNTIF($AD:$AD,$AD{row})"
}
```

`{row}` は自動的に現在の行番号に置き換えられます。

#### カラムマッピングのカスタマイズ

CSV の列と Spreadsheet の列を自由に対応付けできます：

```json
"column_mapping": {
  "氏名": "名前",              // CSV の「名前」列 → Sheet の「氏名」列
  "アドレス": "メールアドレス",  // CSV の「メールアドレス」列 → Sheet の「アドレス」列
  "進捗": "",                  // 空欄 = default_values の値を使用
  ...
}
```

## ❓ よくある質問

### Q1: アップロードボタンが無効（グレーアウト）のまま

**A**: 以下を確認してください：
1. CSV ファイルが選択されているか
2. `config/indeed_config.json` の `enabled` が `true` になっているか
3. GUI の「⚙️ 設定」で「アップロード機能を有効化」にチェックが入っているか

### Q2: 「サービスアカウントファイルが見つかりません」エラー

**A**: 以下を確認してください：
1. `service-account/service-account` ファイルが存在するか
2. JSON形式で正しく保存されているか
3. ファイルの権限が読み取り可能になっているか

### Q3: 重複データがスキップされない

**A**: 以下を確認してください：
1. `duplicate_check_column` の列名が Spreadsheet の実際の列名と一致しているか
2. `skip_duplicates` が `true` になっているか
3. チェック対象の列にデータが存在するか（空欄はスキップされない）

### Q4: 文字化けが発生する

**A**: **このツールは文字化けを自動修復します！**

1. **自動検出機能**
   - `csv_encoding: "auto"` が設定されていることを確認
   - ツールが自動的に6種類のエンコーディングを試行
   - 正しいエンコーディングを自動選択

2. **検出結果の確認**
   - ファイル選択後、GUI に「📝 エンコーディング: shift-jis」のように表示
   - プレビュー画面で文字化けがないか確認
   - `�` のような文字が表示される場合は、下記の対処法を試す

3. **それでも文字化けする場合**
   ```json
   // config/indeed_config.json で順序を変更
   "encoding_fallbacks": [
     "shift-jis",  // 最初に試すエンコーディング
     "cp932",
     "utf-8-sig",
     "utf-8"
   ]
   ```

4. **確実な方法**
   - CSV を Excel で開く
   - 「名前を付けて保存」→「CSV UTF-8」を選択
   - 再度アップロード

**詳細は [CSV文字化け対策ガイド](csv-encoding-guide.md) を参照してください。**

### Q5: 公式が文字列として表示される

**A**: これは正常です。以下を確認してください：
1. アップロード後に Spreadsheet をリロードしてみてください
2. 公式が正しく計算されているか確認してください
3. `formulas` の設定が正しいか確認してください

### Q6: 特定の行だけエラーになる

**A**: ログを確認してください：
- どの行でエラーが発生しているか
- エラーメッセージは何か
- CSV の該当行に不正なデータがないか（改行、特殊文字など）

### Q7: アップロード後に Spreadsheet が見つからない

**A**: 以下を確認してください：
1. Spreadsheet ID が正しいか
2. サービスアカウントに Spreadsheet の編集権限があるか
3. シート名が正しいか（大文字小文字も区別されます）

## 🔧 トラブルシューティング

### ログファイルの確認

エラーが発生した場合、GUI のログエリアを確認してください。

### 設定ファイルの確認

`config/indeed_config.json` の JSON 形式が正しいか確認：
- カンマの位置
- 括弧の閉じ忘れ
- ダブルクォートの対応

### 依存関係の再インストール

問題が解決しない場合、依存関係を再インストール：

```bat
install_indeed_uploader.cmd
```

## 📞 サポート

問題が解決しない場合は、以下の情報を含めて報告してください：

1. エラーメッセージ（ログから全文コピー）
2. 使用している CSV ファイルの列名
3. `config/indeed_config.json` の内容（Spreadsheet ID は隠す）
4. Python のバージョン（コマンドプロンプトで `python --version`）
