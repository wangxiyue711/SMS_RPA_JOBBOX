# CSV 文字化け対策ガイド

Indeed CSV アップロードツールには、強力な文字化け自動修復機能が組み込まれています。

## 🔧 自動エンコーディング検出機能

### デフォルト設定

`config/indeed_config.json` には以下の設定があります：

```json
{
  "csv_encoding": "auto",
  "encoding_fallbacks": [
    "utf-8-sig",
    "shift-jis", 
    "cp932",
    "utf-8",
    "iso-2022-jp",
    "euc-jp"
  ]
}
```

### 動作の仕組み

1. **自動検出モード** (`csv_encoding: "auto"`)
   - ツールが自動的に複数のエンコーディングを試行
   - 最初に成功したエンコーディングを使用
   - GUI画面に検出されたエンコーディングを表示

2. **フォールバックリスト**
   - 上から順番に試行
   - 日本語CSVで一般的なエンコーディングをすべてカバー
   - カスタマイズ可能

## 📋 対応エンコーディング一覧

| エンコーディング | 説明 | 使用例 |
|---|---|---|
| `utf-8-sig` | UTF-8 with BOM | Windows Excel、新しいツール |
| `shift-jis` | Shift-JIS | 古い日本語システム |
| `cp932` | Windows-31J (Shift-JIS拡張) | Windows日本語版 |
| `utf-8` | UTF-8 without BOM | Mac、Linux |
| `iso-2022-jp` | JIS | メール、古いシステム |
| `euc-jp` | EUC-JP | Unix系システム |

## 🎯 使い方

### ケース1: 完全自動（推奨）

**設定（デフォルト）：**
```json
"csv_encoding": "auto"
```

**動作：**
1. CSVファイルを選択
2. ツールが自動的に正しいエンコーディングを検出
3. GUI上に「📝 エンコーディング: shift-jis」のように表示
4. 文字化けなくアップロード完了

### ケース2: 特定のエンコーディングを指定

Indeed の CSV が常に同じエンコーディングの場合：

**設定：**
```json
"csv_encoding": "shift-jis"
```

**メリット：**
- 検出処理をスキップして高速化
- 確実性が高い

### ケース3: カスタムフォールバックリスト

特殊なエンコーディングが必要な場合：

**設定：**
```json
"csv_encoding": "auto",
"encoding_fallbacks": [
  "shift-jis",
  "cp932",
  "utf-8-sig",
  "gbk",
  "big5"
]
```

## 🔍 文字化け確認方法

### プレビュー画面で確認

1. CSV ファイルを選択
2. データプレビュー（最大10件）をチェック
3. 以下のような文字化けがないか確認：
   - `�` （疑問符の四角）
   - `ããã«ã¡ã¯` （UTF-8を間違って読んだ場合）
   - `�@�B�H` （Shift-JISを間違って読んだ場合）

### エンコーディング表示を確認

GUI上の「📝 エンコーディング: xxx」表示をチェック：
- ✅ 緑色 = 正常に検出
- ❌ 赤色 = 読み込み失敗

## ⚠️ トラブルシューティング

### Q1: 「読み込み失敗」と表示される

**原因：**
- すべてのエンコーディングで読み込みに失敗
- ファイルが破損している
- CSV形式ではない

**対処法：**
1. ファイルをメモ帳で開いて中身を確認
2. Excel で開いて「名前を付けて保存」→「CSV UTF-8」で再保存
3. `encoding_fallbacks` に追加のエンコーディングを追加

### Q2: プレビューは正常だがアップロード後に文字化け

**原因：**
- Spreadsheet 側の文字コード問題
- 特殊文字が含まれている

**対処法：**
1. サービスアカウントの権限を確認
2. Spreadsheet を UTF-8 モードで作成し直す
3. 特殊文字（絵文字など）を削除

### Q3: 一部の列だけ文字化けする

**原因：**
- CSV 内に異なるエンコーディングが混在
- 改行コードの問題

**対処法：**
1. CSV を Excel で開く
2. 文字化けしている列のデータを確認
3. 必要に応じて手動修正
4. UTF-8 で再保存

### Q4: 特定のエンコーディングを強制したい

**設定例：**
```json
"csv_encoding": "shift-jis",
"encoding_fallbacks": []
```

これで `shift-jis` のみを使用（フォールバックなし）

## 📊 実際の使用例

### 例1: Indeed ダウンロード（Windows）

**典型的なエンコーディング：** `shift-jis` または `cp932`

**設定（推奨）：**
```json
"csv_encoding": "auto",
"encoding_fallbacks": ["shift-jis", "cp932", "utf-8-sig"]
```

### 例2: Indeed ダウンロード（Mac）

**典型的なエンコーディング：** `utf-8`

**設定（推奨）：**
```json
"csv_encoding": "auto",
"encoding_fallbacks": ["utf-8", "utf-8-sig", "shift-jis"]
```

### 例3: Excel から CSV 出力

**エンコーディング：** Excel のバージョンによって異なる
- Excel 2016以降: `utf-8-sig`
- Excel 2013以前: `shift-jis` または `cp932`

**設定（推奨）：**
```json
"csv_encoding": "auto",
"encoding_fallbacks": ["utf-8-sig", "shift-jis", "cp932", "utf-8"]
```

## 🛠️ 高度な設定

### カスタムエンコーディング追加

中国語、韓国語などの CSV を扱う場合：

```json
"encoding_fallbacks": [
  "utf-8-sig",
  "shift-jis",
  "cp932",
  "gbk",          // 簡体中国語
  "big5",         // 繁体中国語
  "euc-kr",       // 韓国語
  "utf-8"
]
```

## 💡 ベストプラクティス

1. **まずは自動検出を試す**
   - `csv_encoding: "auto"` で開始
   - ほとんどのケースで正常に動作

2. **プレビューで必ず確認**
   - アップロード前に文字化けをチェック
   - 特に名前、住所などの日本語項目

3. **エンコーディング情報を記録**
   - 検出されたエンコーディングをメモ
   - 次回以降の設定に活用

4. **問題が続く場合は Excel 経由**
   - CSV を Excel で開く
   - 「CSV UTF-8」形式で保存
   - 確実に UTF-8 になる

## 📝 まとめ

✅ **ツールに任せる**
- `csv_encoding: "auto"` で自動検出
- ほぼすべてのケースに対応

✅ **確認を怠らない**
- プレビュー画面で文字化けをチェック
- エンコーディング表示を確認

✅ **問題が起きたら**
- ログを確認
- Excel で UTF-8 保存
- フォールバックリストをカスタマイズ

**このツールなら、CSV の文字化けを気にせず安心してアップロードできます！** 🎉
